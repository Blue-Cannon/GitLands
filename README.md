## What is GitBlue?
**GitBlue** is a open source, free/libre git platform or a hosting platform. GitBlue written on **[Crystal Programming Language](https://crystal-lang.org)**. GitBlue is developed by **Blue-Cannon** a indie developer organization in **GitHub** led by **Rogge Ramos**. GitBlue promise is:

> Free/Libre Forever!
